How it works

It lives inside WhatsApp Web.

  1. 01

    Select

    In a chat, open ⋮ → Select messages and tick the ones you want. Ticks you scroll past are kept.

  2. 02

    Export

    Click Export, next to Forward. The ⚙ beside it picks the format, the order and the theme.

  3. 03

    Keep it

    One file lands in your downloads, with the photos, voice notes, videos and documents you selected.

Formats

Looks like WhatsApp. Opens anywhere.

HTML, PDF and images keep the WhatsApp look, in light, dark or your system's theme. This is a real HTML export of a fictional chat; scroll it, play the voice note.

  • HTML

    One page that opens in any browser. Photos, stickers, voice notes and videos play; documents download.

  • PDF

    The same look on A4 pages. Text can be searched and copied.

  • Image

    The same look as one PNG or JPEG. Long chats can be split into parts.

  • ZIP

    chat.md, messages.json and media/ with every original file.

For coding agents

Hand a conversation to a coding agent.

The ZIP holds the chat as Markdown and as structured JSON, with every file in media/, linked from where it was sent. Unzip it and point Claude Code, Codex or any agent at the folder: it reads who said what, the replies and the files.

Privacy

Read-only. Local. Open source.

  • It only reads, and only when you click Export. It never sends, forwards, deletes, reacts to or marks anything as read.
  • Nothing goes to a server and there are no analytics. Besides web.whatsapp.com, its only permission is storage, for your settings.
  • View-once media is skipped on purpose. Files WhatsApp no longer has are reported, never re-requested from the sender's phone.
  • Every file it couldn't save is listed in the export itself. MIT licensed, with every line on GitHub.

Using an unofficial extension with WhatsApp is against its terms of service. This one only reads, but the risk isn't zero. Privacy policy
